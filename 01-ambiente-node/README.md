# 01 — Ambiente Node e primeiro script

## O que foi feito

Configuração do ambiente de desenvolvimento (Node.js, npm, ESLint e Nodemon) e criação d
programa que lê dados de um arquivo e exibe um relatório no terminal.

## O que eu aprendi

- Cada arquivo `.js` no Node é um módulo isolado
- `module.exports` define o que sai de um arquivo e `require` traz esse conteúdo para o
- Objetos agrupam informações relacionadas e são lidos com ponto: `livro1.titulo`

## Como executar

```bash
node mostrar.js
```
